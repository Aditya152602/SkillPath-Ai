## 🚀 Option 1 — GitHub Pages (Zero Setup)

The `index.html` is fully self-contained and deploys directly to GitHub Pages.

### Steps

1. **Fork / clone** this repo
2. Go to **Settings → Pages**
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save**
5. Your site will be live at `https://<your-username>.github.io/<repo-name>/`

That's it — no build step needed!

## ⚛️ Option 2 — Vite + React Project

For a production-ready build with fast HMR and bundling:

### Setup

```bash
# 1. Create a Vite React project
npm create vite@latest skillpath-ai -- --template react
cd skillpath-ai

# 2. Replace src/App.jsx with the provided src/App.jsx
cp path/to/src/App.jsx src/App.jsx

# 3. Install dependencies
npm install

# 4. Run locally
npm run dev
```

### Deploy to GitHub Pages via Vite

```bash
# 1. Install gh-pages plugin
npm install -D vite-plugin-gh-pages

# 2. Add to vite.config.js
#    base: '/<repo-name>/'

# 3. Add deploy script to package.json
#    "deploy": "vite build && gh-pages -d dist"

# 4. Deploy
npm run deploy
```

## 🤖 Tech Stack

- **Frontend**: React 18, CSS Custom Properties (dark/light theme)
- **AI**: Anthropic Claude (`claude-sonnet-4-6`) via `/v1/messages`
- **Storage**: `window.storage` (Claude artifacts) / in-memory fallback
- **Build**: Babel Standalone (HTML) or Vite (JSX)
- **Deploy**: GitHub Pages
